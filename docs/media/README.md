# Media for the README

Drop your screenshots and demo clip here. The README's **See it in action**
section already points at these exact filenames, so once the files exist they
render automatically — no README edits needed.

| File | What to capture | Notes |
| --- | --- | --- |
| `hero.png` | The panel **open** below the notch, showing a few live readouts (internet speed, battery, temperature, tokens). | The main shot. Aim for ~1440px wide; a clean desktop behind it looks best. |
| `demo.gif` | A short 5–10s clip: hover the notch, the panel drops down, maybe media playing in the live strip. | Keep it small (under ~5 MB) so the README loads fast. |

## Capture tips

- **Screenshot a window/region:** `⇧⌘4` (drag a region) or `⇧⌘4` then `Space`
  to grab a single window with its shadow.
- **Retina scaling:** shots come out at 2×. That's fine — the README tags set a
  display width, so they stay crisp without being huge on screen.
- **Record the GIF:** record a clip with `⇧⌘5`, then convert the `.mov` to an
  optimized `.gif` (e.g. with Gifski) and save it here as `demo.gif`.
- **Optional extra shots:** add more images here and reference them in the
  README the same way if you want a fuller gallery.
